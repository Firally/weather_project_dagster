# Система активного обучения для метеорологических данных

## Описание проекта
Этот проект реализует автоматизированный пайплайн для сбора метеорологических данных и дообучения моделей машинного обучения с использованием принципов активного обучения. Система:

1. Каждый час собирает новые метеоданные
2. Оценивает, насколько эти данные "интересны" для обучения на основе разногласий между моделями
3. Сохраняет полезные примеры в тренировочную выборку
4. Еженедельно переобучает модели на обновленном наборе данных

## Структура проекта

```
dagster-project/
├── assets/
│   ├── data_collection.py    # Логика сбора часовых данных
│   ├── active_learning.py    # Оценка и сохранение ценных данных
│   └── model_retraining.py   # Переобучение моделей
├── jobs/
│   ├── data_collection_job.py # Часовой job для сбора данных
│   └── active_learning_job.py # Еженедельный job переобучения
├── data/                     # Директория для хранения данных и моделей
│   ├── training_data.csv     # Накопленные тренировочные данные
│   ├── error_samples.csv     # Сэмплы с ошибками или пропусками
│   ├── model_metrics.csv     # История метрик моделей
│   └── models.pkl            # Сохраненные модели
├── repository.py             # Определение Dagster репозитория и расписаний
├── workspace.yaml            # Конфигурация Dagster
└── requirements.txt          # Зависимости проекта
```

## Пайплайны

### 1. Сбор данных (Каждый час)
`data_collection_job` выполняет следующие операции:
- Запрашивает свежие метеоданные за последний час
- Проверяет качество данных (отсутствие пропусков)
- Оценивает "ценность" данных через голосование моделей
- При высоком стандартном отклонении предсказаний (> 0.5) сохраняет сэмпл

### 2. Обучение моделей (Еженедельно по понедельникам)
`active_learning_job` выполняет:
- Загрузку накопленных данных из training_data.csv
- Разделение на обучающую и валидационную выборки
- Обучение трех моделей (LinearRegression, RandomForest, XGBoost)
- Сохранение моделей и метрик их качества

## Запуск проекта

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск Dagster UI
```bash
dagster dev
```

### Запуск пайплайнов вручную
```bash
# Для запуска сбора данных
dagster job execute -j data_collection_job

# Для запуска переобучения моделей
dagster job execute -j active_learning_job
```

### Расписание
По умолчанию настроено следующее расписание:
- Сбор данных: каждый час (`0 * * * *`)
- Дообучение моделей: каждый понедельник в полночь (`0 0 * * 1`)

Чтобы включить расписание через UI:
1. Откройте http://localhost:3000
2. Перейдите в раздел "Schedules"
3. Включите нужные расписания
